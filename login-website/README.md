# 🚀 composer-post

An automated web application that generates X (Twitter) Video Cards with click-to-redirect links and auto-publishes posts to connected Chrome X profiles.

---

## 📦 Step 1: Upload to GitHub

1. Open **[github.com/new](https://github.com/new)** in your browser.
2. Set Repository Name to: **`composer-post`** and click **Create repository**.
3. Click **"uploading an existing file"**.
4. Drag and drop all files from your project folder:
   - `index.html`
   - `x_card_generator.html`
   - `server.js`
   - `package.json`
   - `render.yaml`
5. Click **Commit changes**.

---

## 🌐 Step 2: Host on Render (Free)

1. Open **[dashboard.render.com](https://dashboard.render.com)**.
2. Click **New +** -> **Web Service**.
3. Connect your GitHub repository (**`composer-post`**).
4. Render will auto-detect settings or enter:
   - **Name:** `composer-post`
   - **Runtime:** `Node`
   - **Start Command:** `node server.js`
5. Click **Create Web Service**.

🎉 Your website will be live at: `https://composer-post.onrender.com`!
